# SARAS Lab

A 3D assembly workbench, an extensible hardware library with compatibility checks, and a complete build tutorial for the SARAS AI robot (Smart Autonomous Robotic AI System), based on Tech With Anant's videos.

**Start with [PLAN.md](./PLAN.md).** It is the source of truth for scope, design (clean beige theme, header, components), architecture, data model, the check/test engine, tutorial content, and the milestone roadmap.

Status: planning (M0). No code yet.
